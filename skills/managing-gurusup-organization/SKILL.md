# Managing your Gurusup organization

Members, invitations, roles, knowledge categories, the plan and the organization's settings. Membership, source access and category grants together decide what each person can read.

Before acting, read the full guide from Gurusup: call the Gurusup `learn` tool with `topic="managing-gurusup-organization"`. If it returns a list of topics instead of the guide, call `learn` with `topic="organization"`. Follow the guide it returns: it is the source of truth and changes as Gurusup does. If neither returns a guide, this part of Gurusup is not available for this organization: say so instead of improvising.

## Hard rules

- Almost everything here is for organization admins. A member can read `organization.settings`, `billing.access` and `setup.status`, and change only their own name and avatar.
- Confirm before inviting, removing someone, changing a role or changing who reads a category. Name the person and explain the effect.
- Category and member-category changes replace the whole list: include everyone and everything that should keep access.
- Payments and plan changes happen on Gurusup's website, not here.
