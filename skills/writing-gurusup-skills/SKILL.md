# Writing Gurusup skills

Call the Gurusup `learn` tool with `topic="skills"` and follow that guide.

1. Check the skills that already exist before writing a new one. Compare purpose and steps, not only names, and propose updating an equivalent skill instead of creating a duplicate.
2. One skill per process: its steps, its sources of truth and when to ask first.
3. Publish only what the user approved. A published or edited skill stays pending until an admin of the organization approves it.
