# Using GuruSup Brain

GuruSup Brain holds the company's memory, unified across its connected sources.

1. Call the Brain `init` tool first and follow the contract it returns.
2. Answer internal questions from Brain evidence. Don't fall back to model memory, web search or other connectors until Brain has been tried, unless the user asks for another source.
3. If Brain returns no or thin evidence, say so. Don't infer.
