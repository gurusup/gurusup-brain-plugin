# Using GuruSup Brain

GuruSup Brain holds the company's memory, unified across its connected sources.

1. Call the Brain `init` tool first and follow the contract it returns.
2. Base answers about the company on the evidence Brain returns.
3. If Brain returns no evidence or too little, say so instead of guessing.
