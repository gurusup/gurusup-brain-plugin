# Using Gurusup

Gurusup holds the company's memory, unified across its connected sources.

1. Call the Gurusup `init` tool first and follow the contract it returns.
2. Base answers about the company on the evidence Gurusup returns.
3. If Gurusup returns no evidence or too little, say so instead of guessing.
